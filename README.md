# Conmigo mismo

Cuaderno personal de reflexión: celular lejos, divagar y escribir.

**Privacidad:** no hay cuentas, servidor, analítica ni publicidad. Todo lo que se escribe se guarda solo en el teléfono de cada persona. La página está bloqueada para conectarse a internet (ver la política de seguridad en `index.html`), así que no puede enviar nada.
